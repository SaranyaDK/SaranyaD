Requirements: Python 3

How to play?
  * The game will generate a random number within a defined range(1 to 20).
  * You will be prompted to guess the number.
  * After each guess, the game will tell you if your guess is too high, too low or correct.
  * If your guess correct, the game will display the number of attempts.
  * There are limited attemps....(just 2 attemps)
  
The code is not too difficult.
